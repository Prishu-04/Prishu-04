## 🚀 Engineering Philosophy

```text
Learn → Build → Break → Debug → Improve → Ship → Repeat
```

1. **Understand before using.** I implement the core idea from scratch first, then reach for the framework.
2. **Measure everything.** If a model, cache or pipeline can't be evaluated, it isn't finished.
3. **Ship it.** Every major project gets a README, architecture notes, tests, an evaluation write-up and a demo.
4. **Build responsibly.** Safety, privacy and failure modes are part of the design, not an afterthought.
